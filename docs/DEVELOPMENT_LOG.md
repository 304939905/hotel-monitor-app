# 酒店监控 APP 开发日志

此文件只追加重要事件。当前稳定事实以 `PROJECT_KNOWLEDGE_BASE.md` 为准。

## 2026-07-15

- 接管 Flutter 安卓项目，确定使用闲置手机、无障碍服务模拟人工操作携程和美团。
- 主页新增“清除”，把所有项目今日查看归零。
- 酒店配置拆分为携程名和美团名，并增加“两平台名称相同”。
- 主体和竞对酒店均允许只填写一个平台，空平台自动跳过。
- 需求从“详情页前四个房型价格”调整为“每家酒店最低起价”。
- 开始在小米 8 SE Android 9 上进行携程真机测试。

## 2026-07-16

- 携程方案改为搜索酒店后读取目标酒店起价。
- 美团方案改为进入详情页，点击筛选、再次点击筛选关闭，再读取房型最低价。
- 美团 OCR 增加稳定等待，排除神券减免数字等非房价。
- 完成后回到桌面并播放提示铃声；“全”支持自定义铃声。

## 2026-07-17 至 2026-07-18

- 完成携程与美团组合批量、多项目和单平台跳过测试。
- 美团增加连续酒店之间返回搜索页、目标卡片名称相似度、满房和错误状态。
- 携程兼容双列卡片、酒店名称换行和顶部“酒店”分类。
- 汇报规则改为：满房显示“满”，其他未取得价格显示“错误”。
- 新增锁屏紧急停止：`ACTION_SCREEN_OFF` 立即清空所有采集任务。
- 用户明确要求无障碍 `onInterrupt()` 也立即结束整次采集，不允许恢复当前步骤。
- 携程从未知详情页启动会导致状态机误入输入步骤；新增启动前复位，逐层返回主页后才开始搜索。
- 真机验证复位流程已成功：从携程酒店详情页返回到主页，再搜索赤雅楼。
- 发现携程页面显示 ¥243，OCR 酒店名匹配成功但价格为空。根因是宣传描述含“酒店”，旧规则提前截断目标卡片范围；同时需要兼容价格与“起”被分行。
- 修复携程价格区域和格式：支持 `¥243`、`￥243`、`243起`，带“起”优先；三次 OCR 失败后立即写入错误并进入下一家。
- 最新修复通过 11 项 Flutter 测试和 Debug APK 编译，已安装，等待下一轮完整真机回归。
- 用户提出可能转为“截图直接展示”以降低价格核验成本；当前仅讨论，尚未开始截图版改造。
- 完成冻结备份“酒店监控文字版26-7-18”：包含源码 ZIP、可安装 APK、版本说明、详细开发交接和 SHA256 校验。
- 建立持续资料库：根目录 `AGENTS.md` 规定上下文恢复与验证规则，`docs/PROJECT_KNOWLEDGE_BASE.md` 保存当前事实，本文件持续追加重要开发记录。
- 用户正式确定转入截图版：价格不再由 OCR 生成文字结论，截图成为最终证据；OCR 仅保留目标酒店校验。
- Android 屏幕采集服务新增整屏 JPEG 保存；携程在结果页确认目标酒店后截图，美团完成两次“筛选”并稳定等待后截图。
- 单项目“采集最低起价”改为执行项目内全部有效酒店/平台；主页“全”继续执行全部项目。
- 界面 A 在采集按钮右侧新增项目级“历史”，汇总展示上一次采集的全部截图；当次截图可点击全屏缩放。
- 实现严格两代轮换：只保存当次和紧邻的上一次，新采集开始时自动删除更早截图文件；结果同步不再逐条挤压历史。
- 新增历史轮换自动测试；共 12 项 Flutter 测试全部通过，截图版 Debug APK 编译通过，等待真机首轮验证。
- 截图版首轮赤雅楼测试确认原生端已生成并保存 3 张截图（携程两家、美团华美达），但主页先同步结果后项目页没有重绘，导致截图不显示且采集按钮不结束；新增原生任务运行状态查询，并让项目页在结果已由主页写入时仍强制刷新。
- 赤雅楼美团搜索结果被平台弹窗遮住标题前半段。美团流程改为：首次无法精确匹配时进入最高相似候选并严格核验详情；失败只重新搜索一次；第二次仍无法确认则截图搜索页并标记 `review` 待人工核验，禁止继续重试。
- 满房、错误和待核验状态现在也会尽量保存现场截图，方便人工核验；不得将这些截图当作已确认价格。
- 上述修复通过 Flutter 静态检查、12 项自动测试和 Debug APK 编译，等待重新安装后的赤雅楼回归。
- 真机回归验证携程两家与美团“相似候选进入后严格核验详情”流程成功；按实测结果将美团第二次点击“筛选”后的稳定等待由 3 秒增加到 4 秒，其他流程不变。
- 主页在“全”左侧新增“总”按钮；点击后按项目分组汇总全部当前采集结果、状态和截图，截图仍可进入全屏查看，免去逐个打开项目核对。
- 根据主页易用性反馈，将“总”和“全”调整为同宽同高的独立整行大按钮；“全”新增 3 秒倒计时确认弹窗，支持取消、立即确认，倒计时结束自动确认，降低相邻按钮误触风险。
- 上述主页功能通过 Flutter 静态检查和 14 项自动测试，Debug APK 编译成功并已覆盖安装到小米 8 SE，等待用户进行界面与按钮行为验收。
- 新增携程/美团更新弹窗守卫：无障碍文字优先、OCR 兜底，只点击暂不/稍后/取消/关闭等安全选项，最多两次；强制更新或无法关闭时保存截图、写入 `update_blocked`、停止整个队列并播放独立警告声。
- 更新弹窗守卫通过 Flutter 静态检查和 15 项自动测试，Android Debug APK 编译成功并覆盖安装到已连接的小米 8 SE；真实弹窗仍需等待平台实际出现后验证。
