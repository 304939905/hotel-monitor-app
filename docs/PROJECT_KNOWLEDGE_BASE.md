# 酒店监控 APP 主资料库

最后更新：2026-11-16

本文只保存稳定、当前有效的产品与技术事实。最新构建、连接手机和待验证事项见 [`CURRENT_STATUS.md`](CURRENT_STATUS.md)；历史过程见 [`DEVELOPMENT_LOG.md`](DEVELOPMENT_LOG.md)。

## 1. 产品目标

酒店监控 APP 运行在一台保持亮屏的安卓手机上。用户启动单项目采集或主页“全”采集后，APP 通过安卓无障碍服务模拟人工操作官方携程、美团 APP，搜索主体酒店与竞对酒店并保存真实页面截图。

核心原则：

- 最终结果以截图为准，OCR 不负责给出价格结论。
- OCR 只用于页面识别、酒店名称匹配和目标校验。
- 不使用平台接口、后台爬虫或自动破解验证码。
- 不得把相似酒店、附近酒店或优惠金额当作目标酒店价格。
- 无法可信确认时记录“错误”或“待核验”，不得猜测。

## 2. 项目与酒店配置

- 一个监控项目包含项目名称、城市、一个主体酒店和零个或多个竞对酒店。
- 每家酒店分别保存美团名称和携程名称；两个平台可以不同名。
- 主体酒店和竞对酒店都允许只填写一个平台。平台名称为空时跳过该平台；两个平台不能同时为空。
- 勾选“两平台名称相同”时只填写一次。
- 编辑项目不得重置创建时间、今日查看次数和已有采集记录。

### 批量添加酒店

“新增/编辑监控项目”窗口右上角有“批量添加”，打开独立全屏文本编辑页。

格式固定为三行一组：

```text
主体酒店
主体酒店的美团名称
主体酒店的携程名称

A
竞对 A 的美团名称
竞对 A 的携程名称

B
竞对 B 的美团名称
竞对 B 的携程名称
```

规则：

- `主体酒店` 段可省略；省略时只向当前项目追加竞对酒店。
- `A/B/C...` 只作竞对分组标记，不保存为酒店名。
- 某个平台没有名称时填写 `1`，导入后转换为空。
- 同一家酒店两个平台都为 `1` 时拒绝导入。
- 导入只回填当前表单，仍需点击项目窗口“保存”才会写入项目。
- 文本框默认显示精简规则和模板；开始输入后提示自动消失。

## 3. 主要界面与操作

### 主页

- “清除”：把所有项目的“今日查看”归零并保存。
- “总 · 查看全部结果”：按项目分组查看所有当前采集状态和截图。
- “全 · 采集所有项目”：采集全部项目中的全部有效酒店和平台。
- “全”使用独立整行大按钮；点击后显示 3 秒倒计时，可取消、立即确认或等待自动开始。
- 长按“全”可选择自定义完成铃声。
- 全部正常完成后播放铃声并停在安卓桌面。

### 单项目页

- 可分别启用或停用携程、美团。
- “采集最低起价”依次执行本项目所有已启用、且平台名称非空的主体/竞对酒店。
- 当前结果按平台和酒店展示截图，截图可全屏查看。
- “历史”只展示紧邻的上一次采集结果。
- 永远只保留“当前”和“上一次”两代截图；更早文件自动删除。

## 4. 携程采集流程

1. 回到安卓桌面，再点击携程图标进入。
2. 第一家酒店前执行页面复位：未知页面逐层返回；回到桌面则重开携程。
3. 最多返回 6 次、重开 2 次；仍不能确认主页时结束整次采集。
4. 从主页进入全局搜索，输入准确酒店名称并搜索。
5. 搜索结果出现后点击顶部“酒店”分类。
6. 兼容单列列表和双列卡片；不能假定目标永远位于左上角。
7. OCR 根据完整名称、换行名称和相似度定位目标酒店。
8. 目标确认后保存包含酒店名称和起价的整屏 JPEG；最多校验/截图三次，仍失败则记录错误并进入下一家。

## 5. 美团采集流程

1. 回到安卓桌面，再点击美团图标进入。
2. 若恢复到旧酒店详情页，先返回；返回桌面时重新打开美团。
3. 搜索准确酒店名称，优先按 OCR 名称相似度定位目标卡片。
4. 首次无法精确识别时，可进入最高相似候选，但必须在详情页严格核验完整酒店名。
5. 候选错误时只允许返回并重新搜索一次；第二次仍无法确认则保存搜索页截图，状态记为 `review`，禁止继续循环。
6. 详情核验成功后点击“筛选”，再寻找并点击“筛选”关闭面板。
7. 第二次点击后等待约 4 秒，使房型价格稳定，再保存详情页整屏 JPEG。
8. 连续采集时，每家完成后返回搜索界面再处理下一家。

## 6. 弹窗、验证码与紧急停止

### 更新弹窗

- 启动携程或美团后先检查更新弹窗。
- 只允许点击“暂不更新、以后再说、取消、关闭”等安全选项。
- 绝不点击“立即更新”。
- 每个平台最多尝试关闭两次；仍被阻挡时保存现场截图、写入 `update_blocked`、停止整次采集并播放警告声。

### 验证码

- 识别到 Yoda/Captcha/Geetest 等安全验证后禁止自动求解或继续点击。
- 保存现场截图、写入 `verification_required`、播放警告声、停止队列并持久化未完成任务。
- 用户人工验证后，可从主页继续剩余任务或放弃；已经完成的结果不重跑、不删除。

### 人工紧急停止

- 使用锁屏键作为紧急停止方式，不使用“任意触摸停止”。
- 收到 `ACTION_SCREEN_OFF` 或无障碍服务 `onInterrupt()` 时立即结束整次采集并清空队列。
- 中断后不恢复当前步骤，也不继续下一家。
- 已完成结果保留；处理中酒店不写成“错误”；不播放正常完成铃声。

## 7. 结果、状态与存储

Flutter 项目数据使用 `shared_preferences`。安卓自动化结果使用 `hotel_automation` SharedPreferences。

主要状态：

- `success`：目标页面校验通过并保存截图。
- `full`：满房。
- `review`：目标无法确认，保存现场供人工核验，不视为成功价格。
- `error`：其他失败。
- `update_blocked`：更新弹窗阻挡，整次采集已停止。
- `verification_required`：需要人工完成验证码。

主要原生键：

- `last_ctrip_capture`
- `batch_ctrip_captures`
- `last_meituan_capture`
- `batch_meituan_captures`
- `completion_sound_uri`
- `captcha_pending_state`

截图保存在 APP 私有目录；卸载 APP 会删除截图和本地项目数据。覆盖安装通常保留数据。

## 8. 技术结构

- Flutter：界面、项目配置、结果展示与任务发起。
- Kotlin：无障碍状态机、屏幕采集、OCR、铃声与平台操作。
- MediaProjection：安卓屏幕采集授权与截图。
- Google ML Kit：中文 OCR。

关键源码：

- `lib/pages/home_page.dart`：主页、全量采集、结果同步、验证码续跑。
- `lib/pages/monitor_page.dart`：单项目采集与结果界面。
- `lib/pages/all_results_page.dart`：全部项目结果汇总。
- `lib/widgets/project_dialogs.dart`：项目编辑和批量添加界面。
- `lib/services/batch_hotel_parser.dart`：批量酒店文本解析。
- `lib/models/monitor_project.dart`：项目、酒店、报告与历史模型。
- `lib/services/collection_service.dart`：平台和酒店任务过滤。
- `lib/services/report_history_service.dart`：两代历史轮换。
- `lib/services/project_storage.dart`：项目持久化。
- `lib/services/android_automation_service.dart`：Flutter/Android 方法通道。
- `android/app/src/main/kotlin/com/hotelmonitor/hotel_monitor_app/HotelAccessibilityService.kt`：自动化状态机。
- `android/app/src/main/kotlin/com/hotelmonitor/hotel_monitor_app/ScreenCaptureService.kt`：截图和 OCR。
- `android/app/src/main/kotlin/com/hotelmonitor/hotel_monitor_app/MainActivity.kt`：授权、通道和铃声选择。

## 9. 兼容性与风险

- 当前主要在 Android 9/10 小米设备验证；Android 11 以上尚未系统回归。
- 携程、美团的页面布局、活动页、更新弹窗和恢复页面可能变化；所有自动化必须有语义判断、次数上限和安全兜底。
- 酒店名称换行、平台名称差异、相似酒店和遮挡弹窗仍可能导致校验失败。
- GitHub 仓库为 `https://github.com/304939905/hotel-monitor-app`；源码、测试和稳定文档纳入 Git，APK 和调试现场不进入 Git。
- 当前 Release APK 使用 Android Debug 签名，只适合测试和侧载；正式分发必须另行建立安全的正式签名配置。
- 重要版本除了 Git tag/Release，仍必须保留外部冻结备份和开发日志。
- `dist/酒店监控截图版_2026-07-18.apk` 是历史分享包，不包含 2026-07-27 的批量添加功能。
