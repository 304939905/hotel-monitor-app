# 酒店监控 APP v1.0.0

发布日期：2026-11-16

源码版本：`1.0.0+1`

这是“页面截图版”的 GitHub 首发测试包。价格以携程、美团真实页面截图为准，OCR 只用于页面识别和目标酒店名称校验。

## 主要功能

- 多监控项目、主体酒店和竞对酒店管理。
- 美团名称与携程名称分开配置，空平台自动跳过。
- 全屏批量添加酒店，支持可选主体、A/B/C 分组和 `1` 转空平台名称。
- 单项目截图采集和主页全部项目采集。
- “总 · 查看全部结果”按项目汇总当前结果。
- “历史”只保留紧邻上一次采集。
- 更新弹窗安全关闭保护。
- 验证码停止、现场截图、未完成任务续跑。
- 锁屏或无障碍 `onInterrupt()` 紧急停止。

```powershell
adb shell getprop ro.product.cpu.abi
```

## 安装

```powershell
adb install -r .\hotel-monitor-app-arm64-v8a-v1.0.0.apk
```

首次打开后：

1. 启用“酒店监控自动化”无障碍服务。
2. 新增监控项目并填写酒店的平台名称。
3. 第一次采集时允许屏幕录制。
4. 先用一家酒店验证，再运行整项目和全部项目。
